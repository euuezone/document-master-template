As-Is 현황 ①  신한투자증권 차세대 프로젝트

여의도 현장관리
⚠ 망분리 환경
진척률 관리
현재 사용 도구
·Jira, Wiki, 엑셀 (함수 기반)
문제 상황
·진척률 취합은 결국 엑셀에 별도 정리
·Jira/Wiki와 엑셀 이중 관리로 반복 작업 발생
·망분리 환경으로 AI 툴 사용 원천 차단
QA 검수 및 관리
현재 방식
·QA 담당자가 검수 내용을 수작업으로 직접 작성
문제 상황
·담당자마다 작성 방식 상이
·맞춤법 오류 빈번
·금융권 전용 용어 불일치로 품질 편차 발생
채널별 통합테스트 예정
현재 방식
·추후 내용 추가 예정

As-Is 현황 ②  2026년 신한투자증권 제안내용_실행 로드맵

UX 라이팅 검수
현재 방식
·UX 라이팅 가이드 문서 보며 수작업 대조 검수
문제 상황
·반복적인 수작업으로 시간·리소스 낭비
·사람마다 기준 해석 편차 발생 가능
분기별 트렌드 보고서
현재 방식
·자료 수집·정리는 AI 활용 중
·보고서 작성은 직접 수작업
문제 상황
·고정 템플릿 없어 매번 포맷 작업 필요
·AI 수집 내용을 보고서로 옮기는 별도 작업 필요
광고심의 문구 검수
현재 방식
·심의 기준 문서 보며 수작업 대조 검수
문제 상황
·단순 반복 작업에 리소스 집중
·검수 누락 리스크 존재
·담당자 의존도 높아 확장성 부족

Pain Point 요약

⚠
환경 제약
›망분리 환경으로 AI 도구 접근 불가
›생산성 격차 발생
🔁
반복 수작업
›기준 문서가 있어도 사람이 직접 대조하는 구조 반복
›검수·작성 전 영역에 걸쳐 수작업 의존
📊
데이터 분산
›Jira/Wiki 사용하나 결국 엑셀로 이중 관리
›실시간 현황 파악 어려움
📋
표준화 부재
›고정 템플릿·자동화 없이 매번 처음부터 작업
›담당자마다 품질 편차 발생
